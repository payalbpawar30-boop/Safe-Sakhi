# Safe Sakhi

Safe Sakhi is a women’s safety web application designed to provide quick access to essential safety features such as SOS alerts, trusted contacts, live location, safe journeys, and emergency check-ins.

## Features

- SOS Emergency Alert
- Trusted Contacts Management
- Add, Edit and Delete Trusted Contacts
- Safe Journey Tracking
- Live Location Sharing
- Emergency Safety Check-in
- Emergency Center
- Activity History
- MongoDB Data Storage
- Docker Containerization
- Responsive User Interface

## Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
- Mongoose

### Deployment and Development
- Docker
- Docker Compose
